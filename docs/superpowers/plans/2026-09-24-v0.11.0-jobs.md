# v0.11.0 — Jobs & flashbacks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A generic heist system: `burgle <premise>` opens a job whose stages (approach, entry, inside, the score, getaway) are derived from the premise the city already generated, whose odds are moved by what the player really cased and really carries, whose failures raise a per-job alarm that can wake the house and summon the watch, and whose Blades-style flashbacks may only claim preparations the player's history makes plausible — proven against HUE & CRY.

**Architecture:** `engine/world/jobs.py`, driven by `paths.jobs`. All job state lives on `GameState.jobs` (a dict), written only through new `apply_effect` kinds. An open job owns the turn exactly as an open encounter does: `legal_intents` offers only the current stage's approaches (verb `job`) plus any legal `flashback`, built per turn from what will resolve. Every stage is a `checks.resolve` roll on bands computed from premise tier, security features, cased intel and carried tools; all randomness on a new `JOB` stream. Time moves only through `advance_time` (each stage costs authored hours); an alarm that reaches full summons the watch through the Law after a delay counted in those hours, from a jobs pass inside `advance_time`. Deeds go through `law.commit_deed`; loot through the `item` kind with `stolen_from`, so it is hot like any lifted ring. The narrator gets a JOB block of band words.

**Tech Stack:** Python 3.11, pytest, PyYAML.

**Spec:** `docs/superpowers/specs/2026-09-23-hue-and-cry-design.md` §4 (Jobs & flashbacks), with §2 (the Law), §3 (Premises) and §6. Read §4 and the cross-cutting rules before any task.

## Data contract (`paths.jobs` → one YAML file)

```yaml
stages:                          # the five derived stages, in order; hours each
  approach: {hours: 1}
  entry:    {hours: 1}
  inside:   {hours: 1}
  score:    {hours: 1}
  getaway:  {hours: 1}

tier_band: {1: easy, 2: standard, 3: hard, 4: severe, 5: legendary}   # base band by premise tier

entries:                         # the entry stage's approaches; each is an option
  door:   {skill: stealth, shift: 0,  label: "the door"}
  window: {skill: stealth, shift: 0,  label: "a window"}
  roof:   {skill: survival, shift: 1, label: "over the roof"}
  cellar: {skill: nerve, shift: 0,    label: "through the cellar"}

approach:                        # the approach stage: getting to the door unseen
  skill: stealth
  shift: -1                      # relative to tier_band; street witnesses roll via the Law
inside:                          # per household member at home
  awake:  {skill: stealth, shift: 0}
  asleep: {skill: stealth, shift: -2}
score:
  skill: craft                   # the strongroom lock / ward
  shift: 0
  draws: {1: 1, 2: 1, 3: 2, 4: 2, 5: 3}     # loot rows drawn from the premise by tier
getaway:
  skill: stealth
  shift: -1

features:                        # security feature id -> what it does to which stage
  greasy_step:    {stage: entry, entries: [door], shift: 1, known_shift: 0}
  hanging_tapers: {stage: inside, shift: 1, known_shift: 0}
  old_mastiff:    {stage: inside, obstacle: true, known_shift: -1}   # an extra obstacle
  warm_vats:      {stage: inside, shift: 1, known_shift: 1}          # known or not, the glow is there

tools:                           # carried item id -> band shift where it applies
  lockpicks:    {stage: [entry, score], entries: [door, cellar], shift: -1}
  smoke_pellet: {stage: [getaway], shift: -1, consumed: true}

alarm:
  max: 4
  bands: [quiet, uneasy, stirring, roused]   # one word per level below max; max is "raised"
  on_fail: 1                     # alarm per failed check
  on_crit_fail: 2
  watch_delay_hours: 2           # after the alarm is raised, hours until the watch arrives
  deed: burglary                 # the Law deed a raised alarm (or a seen member) files

prep:
  max: 3
  per_case: 1                    # earned by each successful `case` (any premise)
  bands: [none, a little, some, plenty]

flashbacks:
  bribed_servant:
    label: "you bribed a servant last week"
    stage: [inside]
    requires: {visited: "{district}"}          # shared condition grammar; {district}/{premise} substituted
    cost: {prep: 1, gold: 5}
    effect: {remove_obstacle: 1}
    exposure: household                         # one household member becomes a real Law witness
  planted_tool:
    label: "you left a bar hidden by the back wall"
    stage: [entry, score]
    requires: {premise_cased: {min: 2}}
    cost: {prep: 1}
    effect: {shift: -2}
  knew_the_rota:
    label: "you knew the rota"
    stage: [approach, inside]
    requires: {premise_cased: {min: 1}}
    cost: {prep: 1}
    effect: {shift: -1}

anchors:                         # authored jobs: an anchored premise's extra stages
  margraves_treasury:
    after: inside
    stages:
      - id: bell_floor
        label: "the vault floor on its springs"
        skill: nerve
        band: severe
        hours: 1
```

Every number above is a **starting point** that Task 6 measures and sets. The loader validates: every stage/skill/band name real (`DIFFICULTY_BANDS`, the story's skills); every `features` key is a security id some premise type or anchor declares (warn-free — a key that matches nothing is a load error naming the file, because an inert row is the "drafting model favours inert shapes" failure); every `tools` key is in the item registry; every flashback `requires` parses through `quests.evaluate_condition`'s grammar (with the two new predicates); `alarm.deed` is a Law deed kind when the Law is declared (and the job commits no deeds when it is not); `anchors` keys are anchored premises; bands lengths match `max`.

## State shape (`GameState.jobs`, a dict; saved; default `{}`) — as built

`prep` and `active` are siblings, never nested one inside the other: `prep`
is earned by casing whether or not a job is open, so it lives on the outer
dict, alone, and `active` carries no `prep` key of its own
(`engine/game/effects.py::_e_job_prep` is its only writer).

```python

 "robbed": ["prem_wickmarket_3"],  # premises a finished job took the score from; `burgle` refuses them
 "seq": 3,                        # counter behind job ids "j<n>"
 "active": {                      # present only while a job is open; `job_open` writes it whole
   "id": "j3", "premise": "prem_wickmarket_3", "district": "wickmarket",
   "stages": ["approach", "entry", "inside", "score", "getaway"],   # anchors splice theirs in
   "at": 2,                       # index into stages
   "alarm": 1,
   "raised_at": None,             # absolute in-game hour (`jobs.now_hour`) the alarm first reached max, else None
   "shifts": {"inside": -1},      # flashback shifts banked for a stage
   "used_flashbacks": ["knew_the_rota"],
   "loot": ["silver_snuffbox"],   # taken at the score, carried out at the getaway
   "log": [{"stage": "entry", "approach": "window", "degree": "success"}],
   # the four keys below are absent until the stage that decides them is
   # reached; `job_stage` is their only writer, and each replaces the key
   # whole rather than merging into it
   "entry": "window",             # chosen at the entry stage; later stages may read it
   "obstacles": ["gen_17", "old_mastiff"],   # the inside stage's remaining obstacles, read once
   "last_flashback": {"label": "you knew the rota", "turn": 41},  # which flashback paid off, and when; never cleared -- only its `turn` equal to the current turn makes it news (`jobs.flashback_label_this_turn`)
   },
 "last": {"id": "j2", "premise": "prem_wickmarket_1", "outcome": "clean", "turn": 41}}   # the last job's close, for the narrator; only `job_close` writes it, and only it clears `active`
```

### Task 2: stages, alarm, the score and the getaway

**Files:** `engine/world/jobs.py` (+`band_for`, `resolve_stage`, `abort`, `tick`), `engine/game/checks.py` (+`shift_band`), `engine/game/effects.py` (+`job_stage`, `job_alarm`), `engine/game/rng.py` (+`JOB`), `engine/game/clock.py` (call `jobs.tick`), intents (verb `job`: options are the current stage's approaches — entry offers `entries`; the other stages offer the stage's single approach plus `abort`), skills `@skill job_stage`, `@skill abort_job`. Test: `tests/test_jobs_stages.py`.

**Interfaces — Consumes:** Task 1's `active`, `stages_for`, `job_open`/`job_close`. `law.commit_deed(state, kind, *, margin, location, certain, exclude, informants)`; `law.declared()`; `premises.get(state, id)`, `premises.known(state, id)`; `npc_sim.resolve_npc`; `checks.resolve(state, skill, difficulty, *, extra_mod, rng)`; `inventory.holds`.
**Produces:**
- `checks.shift_band(band: str, steps: int) -> str` (clamped).
- `jobs.band_for(state, stage, approach=None) -> tuple[str, list[str]]` — the band and the human reasons that moved it (`"lockpicks"`, `"the unlatched window you found"`, `"an unknown greasy step"`). Base = `tier_band[tier]` shifted by the stage's `shift`, then every security feature of the premise that applies to this stage/approach (its `known_shift` if that feature id is in `premises.known`, else `shift`), then each carried tool that applies, then banked flashback `shifts[stage]`.
- `jobs.resolve_stage(state, approach) -> dict` receipt `{ok, stage, approach, band, reasons, degree, outcome, alarm_band, witnesses, loot, closed}`; `outcome` ∈ `clean | noisy | seen | hurt | aborted | caught`.
- `jobs.alarm_band(state) -> str`.
- `jobs.tick(state, hours) -> None` — if the alarm is raised and `raised_at + watch_delay_hours` has passed while the job is still open, closes the job `caught` and opens the Law's arrest encounter (`law.spec()["arrest"]["encounter"]` via `encounter.begin`) — the same door the patrol uses; with no Law declared, the job closes `aborted` with the household awake and nothing else.

Rules:
- Each `resolve_stage` spends the stage's `hours` through `advance_time` BEFORE rolling (the house moves on while you work: household presence is read after the hours pass), rolls on `world_rng(state, JOB)`, then writes through effects. An abort spends no time and closes the job `aborted` (nothing carried out).
- **approach**: roll; street witnesses via `law.commit_deed(state, "loitering", margin=<the roll's margin>)` when the Law is declared and declares `loitering` (a person watching a door at 2am is remembered, never reported on its own).
- **entry**: the chosen entry is recorded; roll.
- **inside**: obstacles = household members `npc_sim.resolve_npc` puts at the premise's `home` now (awake → `inside.awake`, asleep/unavailable → `inside.asleep`) plus every `obstacle: true` feature. One roll per turn against the first remaining obstacle; success removes it; the stage advances when none remain.
- **score**: roll; on success draw `draws[tier]` rows from the premise's `loot` on the `JOB` stream (anchors: their fixed list, all of it), held in `active.loot` (not yet in inventory); if the premise's `secret` is known intel, the receipt names it (the narrator learns it).
- **getaway**: roll; on success the loot is added via the `item` kind with `stolen_from: <premise name>` (hot), and the job closes `clean` if alarm is 0 else `noisy`. Commit the `burglary` deed (Law declared) with the getaway margin — witnesses are whoever is on the street.
- **Failure degrees** (per stage, on the roll's `degree`): failure → alarm `+on_fail` and outcome `noisy`; crit failure → alarm `+on_crit_fail` and, inside, the obstacle member SEES you: `law.commit_deed(state, alarm.deed, certain=[npc])` → outcome `seen`; a crit failure on `entry` via roof/cellar → `hurt` (an `hp` effect, one point; the story's death rules apply). The stage does not advance on failure; the player may try again (new hours, new roll) or abort.
- **Alarm raised** (reaches `max`): `raised_at` = the absolute in-game hour now; commit the deed with every household member at home as `informants` (the house shouts for the watch); the job stays open — the player may still grab and run — and `tick` brings the watch after `watch_delay_hours` of further stage time.
- Tests: band arithmetic for each modifier type (unknown vs known feature; tool only on its stages/entries; clamping at trivial/legendary); failure raises alarm and does not advance; crit fail inside makes a real Law witness; a raised alarm + two more stage-hours opens the arrest encounter and closes the job `caught`; a clean run adds hot loot (provenance written) and marks the premise robbed; `burgle` then refuses it; abort carries nothing out; replay: same seed + same choices → identical receipts; advancing time by other means (rest) with a job open does not roll anything but DOES run `tick`; flagship + Law-only control unchanged.
- [ ] Failing tests → implement → green → full suite → commit `wip T2: stages, alarm, score, getaway`.
