# v0.10.0 — The Law Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A generic Law system — deeds seen by whoever is really present, reports that travel person to person on in-game hours and degrade as they go, a wanted level per guise per jurisdiction, patrols that recognise you, arrest, and custody you can pay or serve out — proven against HUE & CRY.

**Architecture:** `engine/world/law.py`, driven by `paths.law`. All Law state lives on `GameState.law` (a dict), written only through new `apply_effect` kinds. Witnessing happens at the deed (inside the skill that commits it); propagation runs in a law pass inside `clock.advance_time`, one step per elapsed in-game hour, on the `LAW` stream. Arrest reuses the encounter machinery: the story authors an encounter, `law.yaml` names it, and its outcomes use a new `arrest` effect kind. The narrator gets a LAW block with band words only.

**Tech Stack:** Python 3.11, pytest, PyYAML.

**Spec:** `docs/superpowers/specs/2026-09-23-hue-and-cry-design.md` §2 (the Law) and §6. Read both before any task.

## Data contract (`paths.law` → one YAML file)

```yaml
roles: [watch, sergeant, captain]          # schedule roles that ARE the law
reporters: {vendor: 0.3, servant: 0.5}      # chance per witness of going straight to the watch
jurisdictions:                              # every law-relevant location in exactly one
  dockside: [tallow_docks, wickmarket]
deeds:                                      # kind -> severity; unknown kinds are a load error
  pickpocket: {severity: 1}
  loitering:  {severity: 0}                 # remembered, never reported on its own
  fencing:    {severity: 2}
  assault_watch: {severity: 5}
notice:                                     # witness chance, before modifiers
  base: 0.6
  night: -0.25                              # time_of_day in (night, dusk) -- read the engine's labels
  per_margin: -0.05                         # per point of the deed's stealth margin (clamped)
wanted:
  bands: [unknown, noticed, sought, wanted, hunted]
  thresholds: [0, 2, 5, 9, 14]
  cool_per_day: 1.5
precision: {1: 1.0, 2: 0.6, 3: 0.3}         # by hop
recognise: {sought: 0.25, wanted: 0.5, hunted: 0.8}   # chance per law NPC present, x precision
guises:
  self:   {label: "your own face"}
  magpie: {label: "the Magpie's mask", item: magpie_mask}
  porter: {label: "a porter", item: porters_smock}
links: [[self, magpie]]                     # what the watch believes at the start
arrest:
  encounter: watch_stop                     # a story-authored encounter id
  gaol: lantern_house                       # a real location id
  fine_per_severity: 6
  days_per_severity: 1
```

Every number above is a **starting point** that Task 7 measures and sets.

## State shape (`GameState.law`, a dict; saved; default `{}`)

```python
{"guise": "self",
 "links": [["self", "magpie"]],
 "deed_seq": 4,     # counter behind deed ids "d<n>"; written by the first Law effect needing one
 "witness_seq": 12, # counter behind witness ids "w<n>"; written by the `witness` effect
 "witnessed": [   # one row per witness per deed; propagation copies rows with hop+1
   {"id": "w12", "deed_id": "d4", "deed": "pickpocket", "severity": 1, "guise": "self",
    "npc": "gen_x", "where": "wickmarket", "day": 2, "hop": 1, "precision": 1.0}],
 "reports": [     # a witness row that reached a law NPC (or a reporter)
   {"deed_id": "d4", "deed": "pickpocket", "severity": 1, "guise": "self",
    "jurisdiction": "dockside", "precision": 1.0, "day": 2}],
 "custody": {"fine": 6, "days": 1, "since_day": 3, "jurisdiction": "dockside",
             "guise": "self",
             "charged": ["d4"]},  # deed ids this arrest charged; closed by
                                  # `pay_fine`/`serve` through `law_discharge`
 "discharged_deeds": ["d4"],  # deed ids paid for or served out; `report` and
                              # `witness` refuse them from then on
 "quashed": {"wick": ["d4"]},  # per jurisdiction, deed ids a bribe lost
                               # (`quash_reports`); `report` refuses them THERE
 "last_deed": {"id": "d4", "turn": 17, "where": "wickmarket"},
                               # the last committed deed if it was seen
                               # (`law_last_deed`; an unseen deed removes it).
                               # law_block's "you were seen" reads it only
                               # when turn == state.turn_number
 "cool": {"dockside": {"self": 0.4}}}  # per-jurisdiction per-guise cooling
                                       # offset, capped by `law.cap_cooling`
```

**One deed, one id** (Task 2 fix, controller ruling). Every witness row and
report of one committed deed carries the same `deed_id`; a propagated copy
(Task 3) keeps it. `law.filed_score` counts each `(deed_id, filed guise)` ONCE
per jurisdiction, at its best precision -- a lift seen by three watchmen is one
severity, and a hop-2 report of a deed adds nothing to a hop-1 report of it.
Cooling caps and `quash_reports` go through the same de-duplicated score. A
report row without a `deed_id` counts as its own deed.

### Task 1: the Law's data and wanted levels

**Files:** create `engine/world/law.py`; `engine/game/state.py` (+`law`); `engine/game/rng.py` (+`LAW`); `engine/game/effects.py` (+`report`, `quash_reports`); `config/default.yaml` (`paths.law: ""`); register any memo in `engine/games/caches.py`. Test: `tests/test_law.py`.

- Loader validates the contract above; faults raise `ValueError` naming the file (unknown deed kind referenced anywhere, a location in two jurisdictions, bands/thresholds length mismatch, non-ascending thresholds, a guise item that is not in the item registry, an `arrest.gaol` that is not a location).
- `wanted_score(state, guise, jurisdiction) -> float` = Σ severity × precision over `reports` matching both; `wanted_band(...) -> str` via thresholds. Links: a report against guise A also counts for guise B when A and B are linked (the watch believes they are one person) — `links` is symmetric.
- `report` effect appends a report row; `quash_reports` effect removes reports matching `{jurisdiction?, guise?, max_severity?}` (the bribe thread's discharge effect in Task 7).
- `cool(state, days)`: every report's weight decays — implement as reducing an accumulated `cool` offset per jurisdiction by `cool_per_day × days`, floored so a score never goes below 0; written through an effect (`law_cool`) — never mutate state directly.
- Tests: bands at each threshold; linked guises share heat; unlinked do not; quash removes only matching; cool lowers the band over days and never below `unknown`; undeclared → every call inert and `state.law == {}`; flagship save round-trips with `law: {}`; malformed files each raise naming the file.

### Task 2: deeds and witnesses

**Files:** `engine/world/law.py` (+`commit_deed`), `engine/game/effects.py` (+`witness`), `engine/world/thievery.py` (lift emits `pickpocket`: always witnessed by the mark when `noticed`, others roll), `engine/world/premises.py` (case emits `loitering`), `engine/game/trade.py` (an honest vendor refusing hot goods: emits `fencing` witnessed by that vendor, who is treated as a reporter). Test: `tests/test_law_witnesses.py`.

- `commit_deed(state, kind, *, margin=None, location=None, certain=())` — candidates are everyone `npc_sim.npcs_at(state, location or state.location_id)` who is `available` (asleep people see nothing), excluding interior-only people when the deed is on the street. Each rolls on `world_rng(state, LAW)` against `notice.base + night + per_margin × margin` (clamped 0.05..0.95); `certain` npc ids witness without rolling. Each witness → one `witness` effect row, hop 1, precision 1.0, current `guise`. A witness whose role is in `roles` produces a `report` immediately; a witness whose role is in `reporters` produces one with that probability.
- Returns `{"witnesses": [npc ids], "reported": bool}` — attached to the calling skill's result as `seen_by` so the narrator is told before it writes (display names only, via summarisers).
- Rolls happen only when a deed is committed — never during prompt build or `legal_intents`.
- Tests: nobody present → nobody sees; asleep people never see; a noticed lift is always witnessed by the mark; night lowers the rate (measured over 200 seeded deeds, not asserted per-roll); a watchman witness reports at once; loitering is recorded but a lone loitering deed never raises wanted above `unknown`; replay from seed; flagship lift/case/sell unchanged.

### Task 3: reports travel

**Files:** `engine/world/law.py` (+`propagate`), `engine/game/clock.py` (call `law.propagate(state, hours)` then `law.cool(state, days)` in `advance_time`, after NPC refresh; guarded by `law.declared()`), `engine/world/gossip.py` (the background gossip pass skips anything the Law owns — witness rows are not ledger facts, so confirm there is no overlap and say so in a comment). Test: `tests/test_law_propagation.py`.

- For each elapsed in-game hour (cap the loop at 48 steps per call; a long sleep propagates at most two days): for each district, the available NPCs present; each witness row held by a present NPC may be told to one other present NPC with probability `spread_per_hour` (a law.yaml key, default 0.3) on `world_rng(state, LAW)`, producing a new witness row with `hop + 1` and `precision = precision[hop+1]`; never beyond hop 3; a listener never receives the same deed at an equal or lower hop (the v0.7.2 gossip rule). A row reaching a law-role NPC becomes a report at that row's precision.
- Deterministic: iterate districts and NPCs in sorted order.
- Tests: a deed witnessed by a baker reaches the watch through a shared room within N hours; precision decays by hop; hop 4 never happens; same seed + same `advance_time` calls → identical reports; the background tick (`WorldSim.on_tick`) does not propagate on its own schedule (propagation depends on hours passed, not calls made — advancing 1h twelve times equals advancing 12h once, within the loop cap); flagship `advance_time` unchanged.

### Task 5: patrols, arrest and custody

**Files:** `engine/world/law.py` (+`recognition(state)`), `engine/scenes/default_state.py` (after intent execution, before narration: if not in custody and no encounter open, run `recognition`; on a hit begin `law.yaml arrest.encounter` via `engine/game/encounter.begin`), `engine/game/effects.py` (+`arrest`: relocate to `arrest.gaol`, confiscate every carried unit whose `thievery.heat` is `hot` via `remove_item` + `provenance`, set `custody {fine, days, since_day}` from the sum of severities of reports in this jurisdiction; +`release`: clear custody), intents (`pay_fine` when in custody and gold ≥ fine; `serve` when in custody — `serve` calls `advance_time(days × 24)` and releases; while in custody, travel is not offered — rest IS still offered, rule 6), `engine/skills/builtin/law.py` (+`pay_fine`, `serve_sentence`), summarisers. Test: `tests/test_law_arrest.py`.

- `recognition`: for each law-role NPC present and available, if the current guise's band in this jurisdiction is in `recognise`, roll `recognise[band] × best precision among matching reports` on `LAW`. First hit wins; one check per turn.
- The `arrest` effect is the only way location changes outside graph travel; document that in its docstring.
- Tests: `unknown`/`noticed` never recognised; `hunted` with precision 1.0 recognised often (measured); a hit opens the encounter; an encounter outcome carrying `{type: arrest}` moves you to the gaol, confiscates only hot goods, sets custody; `pay_fine` needs the gold and releases; `serve` advances exactly days × 24 through `advance_time` and releases; rest is offered in custody and travel is not; no recognition roll while an encounter is open or in custody; flagship turn unchanged.
