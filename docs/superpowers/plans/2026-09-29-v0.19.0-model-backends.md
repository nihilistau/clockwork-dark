# v0.19.0 — Model-server agnostic — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The game narrates through LM Studio (unchanged, still the default), vLLM, llama.cpp's `llama-server`, Ollama or any OpenAI-compatible server. One key selects the server: `llm.provider`.

- LM Studio receives byte-identical requests, and parses its responses identically, from both the shipped config and any existing `config/local.yaml`.
- Every other provider gets:
  - discovery;
  - the strongest structured output it supports, with a fallback that still parses the narration envelope and still keeps rule 1;
  - reasoning control and a starvation retry that never starves on every turn;
  - health checks in `launcher.py --check` / `--stack` and `scripts/doctor.py`.

**Architecture:**
- A `Provider` table (`providers.py`) is the capability matrix as code. The backend, clients, discovery, stack and doctor read it and never branch on a provider's name.
- vLLM, llama-server and generic servers ride the existing OpenAI-compatible client, shaped per provider.
- Ollama gets a native `/api/chat` transport, because only that route sets `num_ctx` and `think` alongside a grammar.
- The MCP tool loop stays LM Studio-only.
- Every provider module is added **in place under `engine/lmstudio/`** (Tasks 3–6). The package moves to `engine/llm/`, with an identity shim, in **Task 7**, the last code task: zero logic, guarded by a golden that has been stable since Task 1.

**Tech Stack:** Python 3.11, pytest, httpx (every non-live test patches `httpx.HTTPTransport.handle_request` through `tests/llm_wire.py`), PyYAML.

**Spec:** `docs/superpowers/specs/2026-09-29-model-backends-design.md`. The spec's § numbers are cited per task. Its "Findings the survey turned up" 1–5 are each fixed by a named task below, with a failing-first test. The design review (`.superpowers/sdd/2026-09-29-v0.19.0-model-backends/design-review.md`) and the controller's rulings on it (`progress.md`, "Design review") are folded into both documents.
