# v0.24.0 — Sound for the engine and every story, READ RECEIPTS' carried tail, and v0.23.0's deferred close — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every story makes sound: buttons, choices, turns, rolls, errors and a dropped link for all seven, each story in its own palette, and READ RECEIPTS as a phone (messages, notifications, typing, sending, ringtones, buzz, lock, raise). The player sets a master volume, five category levels, narration, mute and a quiet interface. An audition page plays every sound and shows its data key. READ RECEIPTS gains the morning after a stay-over and four more life-event decks, and the lift's minutes stop applying to every move. Then v0.23.0 is closed: the balance pass, live play, docs and the whole-branch review.

**Architecture:**
- **Sounds are data.** The engine's set is `content/sounds/sounds.yaml` (config `sound.root`). A story adds or overrides through `paths.sounds`. The server (`engine/games/sounds.py`, `engine/api/sounds.py`) only loads, checks, merges and serves; it never plays anything, and no turn or phone payload gains a sound key.
- **The client** (`ui/src/core/sound/`) is one small API, called DIRECTLY where each thing happens: `playSound`, `markSeen`, `useSoundOnChange`, `turnSent`/`turnSettled`, `installClickSounds`, `useSoundLevels`. There is no dispatch wrapper and no reducer hook.
- **Three firing rules** (spec §6.3): only NEW events, keyed with a bounded seen-set; state-change cues only inside a turn this page sent; one sound per action.
- **Synth for the interface, Kenney CC0 Ogg for foley**, every file with a synth fallback chosen by a `canPlayType` probe; 1 MiB of audio in all.
- **READ RECEIPTS' tail** is engine work in `engine/social/scene.py`, `engine/social/world.py` and the story's data, gated on `paths.social` as v0.23.0's was.

**Tech Stack:**
- Server: Python 3.11, Flask 3.1 with Flask-SocketIO 5.6, PyYAML (libyaml).
- Python tests: pytest with pytest-xdist and pytest-timeout.
- Client: React 18, Vite 5, Web Audio, vitest 2 with jsdom, and playwright-core for the layout check.
- Client tests follow the repo's convention: `// @vitest-environment jsdom` on line 1, `createRoot` plus `React.act`, and the helpers in `ui/tests/helpers/dom.js` (`mount`, `click`, `key`, `typeInto`, `button`, `byTestId`, `byText`). **No `@testing-library/react`.**

Section numbers (§N) and task numbers (T1-T15) below are the spec's. The review and its re-review: `docs/superpowers/specs/2026-10-23-v0.24.0-sound-design.REVIEW.md`. The owner's brief: `docs/superpowers/briefs/2026-10-13-sound-effects-brief.md`. Where this plan and the spec disagree the spec wins, unless a **Plan decision** below says why not.

## Plan decisions

Places where the code disagrees with the spec or the spec is silent. Each is binding unless the spec is revised.

1. **A message's sound key is `<thread_id>@<last.at>`, not a message id.** The phone payload's thread row (`engine/social/messaging.py::_thread_row`) carries `last: {from, kind, at, preview, pending}` with no message id, while a `phone_message` push carries the message with its id. Keying by id on one carrier and by row on the other would sound one message twice. `(thread_id, at)` identifies a message in BOTH carriers, so it is the one key (spec §6.3 rule 1's intent; §9.7's "keyed by its id"). A row with `pending: true` (not yet voiced) is not sounded until it is voiced.
2. **The scene id** (spec §9.7, §12.1) is `<pid>@<started_at>`, added to `_scene_section` as `id` in T1, together with `kind`.
3. **The plugin field is `soundEvents` only** (spec §5.2): no `soundFor`. Story events are fired from plugin components with `playSound` or `useSoundOnChange`.
4. **`useSoundOnChange` plays a new value when a sent turn is IN FLIGHT at effect time** (pre-flight F1). A turn's result and `busy: false` arrive in one reducer action, so the drawing component (a descendant of App) and App re-render in one commit, and React runs the child's effect first: at that moment `inSentTurn()` (`sent > settled`) is still true, because App's `turnSettled()` runs after. The hook runs on EVERY render (no deps), recording the value and the settled counter each time, and plays when the value changed (and passes `when`) and `inSentTurn()` is true. The ruling's second clause ("or the settled counter moved since its last record") is NOT implemented: with the record refreshed on every render, the counter moves in the turn's own commit AFTER the child's effect, so the clause would fire on the NEXT unrelated change (a resume raising a value), which `sound-turns.test.jsx`'s hydration case pins as silent; no component re-renders in a later commit than App's settle with the turn's change still pending, so in-flight alone covers every cue. Mount and hydration (a load, a resume, a rejoin: no sent turn in flight) are silent, logged as `dropped: "not_my_turn"` when the play log is on.
5. **Engine events and sound ids may share a name** (`ui.toggle` the event, `ui.toggle` the sound): they are separate namespaces in the data (`bind:` keys vs `sounds:` keys).
6. **The engine's file sounds are synth until T7** (spec §16): T3 ships `roll.dice` as a synth rattle; T7 turns it into a file row with that synth as its fallback.
7. **READ RECEIPTS' `scene.open` fires from `PlayScreen`'s sound hook, not from `World.jsx`'s companion card** (spec §9.7 names the card). React runs a child's effects before its parent's, so a card effect would play before `PlayScreen` had run `hydrate` on a resume. One hook in `PlayScreen` does hydration first, then messages, then the scene, keyed by `phone.scene.id` as the spec says.
8. **`phone.send` plays when the compose bar hands the action to the sender** (spec §9.7: "when the action is accepted"). The composer's own checks (empty, over the cap, a chip missing) refuse without a sound; a refusal from the server later shows as not-sent and plays nothing more.
9. **All fifteen files live in the ENGINE's tree** (`content/sounds/files/kenney/...`), and the stories reuse them by `engine:` paths (spec §3). No story ships a `files/` directory or a `PROVENANCE.yaml` in v0.24.0, so nothing is counted twice against the budget, and the provenance test has one file to read.
10. **The API beyond spec §6.1's list.** Public: `useRollSounds(dice)` (the cast and the delayed degree, keyed `roll:<at>`), used by core's `RollCard` and the flagship's `DiceToast` (pre-flight F10). Core-internal, never imported by a story: `ui/src/core/sound/hooks.js` (`useTurnSounds`, `useLinkSounds`; App only), `turns.js`'s `inSentTurn`, `engine.js`'s `limits`, `playCount` and `oggSupported` (the last for `Audition.jsx`, pre-flight F29). `useSoundVolume` is DROPPED: READ RECEIPTS gets the prefs as props (decision 13).
11. **`game.ending` fires from App**, where the ending screen is chosen, with `useSoundOnChange` on the ending's id, so it sounds for every plugin, the Garden's own `Ending` included (pre-flight F10). The flagship's `EncounterPanel` and NEON CITY's `Stage` call `useSoundOnChange(live, "encounter.start", {when: (a, b) => !a && b})` themselves, since they own the `encounter` panel.
12. **`turn.arrive` needs a turn payload and a live link** (pre-flight F11). App counts `turn_update`s in a ref (its existing `socket.on("turn_update")` handler) and passes the count to `useTurnSounds`; a settle with no new `turn_update` (a socket drop sets `busy: false` with no error) or with the link not `live` is silent (`link.lost` speaks for it). `turnSent({begin: true})` marks a new run's entry, and its settle plays nothing: `game.begin` already did. `turnSettled()` returns `false` or the settled entry (`{begin}`), which is truthy.
13. **READ RECEIPTS receives the prefs as props** (pre-flight F13): App passes `prefs` and `onPrefs={updatePrefs}` to a story `PlayScreen` (optional props; a `story.js` contract line); `PlayScreen` passes both to its Settings app and `prefs` to `VoiceTile`.
14. **READ RECEIPTS hydrates on `openSeq`** (pre-flight F12): `state.js`'s `opened()` bumps a new `openSeq` on EVERY `game_started` and `game_resumed` (a rejoin included), touching neither `lockSeq` nor the screen; `PlayScreen` hydrates when it changes.
15. **`phone.match` is a new DATING-APP thread with no message** (pre-flight F14): `app` in `matchstick` or `front_porch` (`ui/src/stories/read-receipts/phone/apps.js`). A `texts` thread opened by a number swap is not a match.
16. **The delegated press defers to a microtask** (pre-flight F17): `ui.press` is skipped when any sound played during that click's dispatch (React 18 flushes a discrete event's effects synchronously, so a `Modal`'s `ui.open` is counted first). The engine's `playCount()` is the counter.
17. **One licence file per pack** (pre-flight F20): `LICENSES/kenney-<pack-slug>.txt`, each row's `licence_file` naming its own; spec §3 names one path (`kenney-cc0.txt`), but each pack's `License.txt` names its own pack and date, so one file would keep only the last. T13's AUTHORING text follows.
18. **Recorded deviations** (pre-flight F27): `check()`'s signature is `check(data, *, where, root, story, engine_sounds=None, engine_root=None)` (spec §4.4 writes `story_events`; the story's events come from `data` itself); the parse cache is keyed `(path, mtime)` (the path names the story, so `slug` adds nothing); the FIRST play of a file sound is its fallback while the file loads (spec §6.4 is silent on it); and `dropped: "not_my_turn"` is written by `useSoundOnChange`'s silent skips.
19. **A suspended context still schedules** (pre-flight F33): `play` drops a sound (`locked`) only when no `AudioContext` exists yet; with one in `suspended` (a real browser's `resume()` is asynchronous; a background tab), it calls `resume()` and schedules anyway, and Web Audio plays it on resume.

```python
def _fault(where: str, key: str, message: str) -> SoundError:

def _num(value: Any) -> bool:
    return isinstance(value, (int, float)) and not isinstance(value, bool)


def _range(where: str, key: str, value: Any, low: float, high: float) -> float:
    if not _num(value) or not low <= float(value) <= high:
        raise _fault(where, key, f"must be a number from {low:g} to {high:g}")
    return float(value)


def _keys(where: str, key: str, row: Any, allowed: frozenset[str]) -> dict[str, Any]:
    if not isinstance(row, dict):
        raise _fault(where, key, "must be a mapping")
    for extra in sorted(set(row) - allowed):
        raise _fault(where, f"{key}.{extra}" if key else extra, "is not a key here")
    return row


def exists_exact(root: Path, rel: str) -> bool:
    """`rel` (a '/' path) names a file under `root` with EXACTLY that case: each part is in its parent's listing.
    `Path.exists()` is case-blind on Windows and would pass a name that 404s on Linux (rule 11)."""
    here = Path(root)
    parts = rel.split("/")
    for i, part in enumerate(parts):
        try:
            names = os.listdir(here)
        except OSError:
            return False
        if part not in names:
            return False
        here = here / part
    return here.is_file()


def _layer_ms(layer: dict[str, Any]) -> float:
    return sum(float(layer.get(k, 0) or 0) for k in ("start_ms", "attack_ms", "decay_ms", "hold_ms")) + float(
        layer.get("release_ms", 20) or 0)


def _check_layer(where: str, key: str, layer: Any, *, voice: bool = False) -> None:
    _keys(where, key, layer, LAYER_KEYS - ({"freq", "to", "glide_ms"} if voice else frozenset()))
    wave = layer.get("wave")
    if wave not in WAVES:
        raise _fault(where, f"{key}.wave", f"must be one of {', '.join(WAVES)}")
    if not voice and wave != "noise":
        _range(where, f"{key}.freq", layer.get("freq"), 20, 16000)
    if "to" in layer:
        _range(where, f"{key}.to", layer["to"], 20, 16000)
    for name in ("glide_ms", "start_ms", "attack_ms", "decay_ms", "hold_ms", "release_ms"):
        if name in layer:
            _range(where, f"{key}.{name}", layer[name], 0, MAX_MS)
    for name, high in (("gain", 1), ("sustain", 1)):
        if name in layer:
            _range(where, f"{key}.{name}", layer[name], 0, high)
    if "detune" in layer:

    if "filter" in layer:
        flt = _keys(where, f"{key}.filter", layer["filter"], FILTER_KEYS)
        if flt.get("type") not in FILTERS:
            raise _fault(where, f"{key}.filter.type", f"must be one of {', '.join(FILTERS)}")
        _range(where, f"{key}.filter.freq", flt.get("freq"), 20, 16000)

    if "tremolo" in layer:
        trem = _keys(where, f"{key}.tremolo", layer["tremolo"], TREMOLO_KEYS)

def _check_synth(where: str, key: str, synth: Any) -> None:
    _keys(where, key, synth, SYNTH_KEYS)
    if ("layers" in synth) == ("sequence" in synth):
        raise _fault(where, key, "needs exactly one of layers and sequence")
    total = 0.0
    if "layers" in synth:
        layers = synth["layers"]
        if not isinstance(layers, list) or not 1 <= len(layers) <= 6:
            raise _fault(where, f"{key}.layers", "must list 1 to 6 layers")
        for i, layer in enumerate(layers):
            _check_layer(where, f"{key}.layers.{i}", layer)
        total = max(_layer_ms(layer) for layer in layers)
    else:
        seq = _keys(where, f"{key}.sequence", synth["sequence"], SEQUENCE_KEYS)
        _check_layer(where, f"{key}.sequence.voice", seq.get("voice"), voice=True)
        notes = seq.get("notes")
        if not isinstance(notes, list) or not 1 <= len(notes) <= 32:
            raise _fault(where, f"{key}.sequence.notes", "must list 1 to 32 notes")
        for i, note in enumerate(notes):

            if not ok:
                raise _fault(where, f"{key}.sequence.notes.{i}", "must be [at_ms, Hz or a note name, length_ms]")

    _keys(where, key, row, SOUND_KEYS)
    if row.get("category") not in CATEGORIES:
        raise _fault(where, f"{key}.category", f"must be one of {', '.join(CATEGORIES)}")
    if not isinstance(row.get("label"), str) or not row["label"].strip():
        raise _fault(where, f"{key}.label", "is required: the audition page's words")
    if ("synth" in row) == ("file" in row):
        raise _fault(where, key, "needs exactly one of synth and file")
    for name, low, high in (("gain", 0, 1), ("throttle_ms", 0, 10000), ("rate", 0.5, 2), ("start_ms", 0, MAX_MS)):
        if name in row:
            _range(where, f"{key}.{name}", row[name], low, high)
    if "synth" in row:
        _check_synth(where, f"{key}.synth", row["synth"])
        return
    _check_file(where, f"{key}.file", row["file"], root, engine_root)
    if "fallback" not in row:
        raise _fault(where, f"{key}.fallback", "every file sound needs a synth fallback (spec §4.2)")
    _check_synth(where, f"{key}.fallback", row["fallback"])


def check(data: Any, *, where: str, root: Path, story: bool, engine_sounds: Optional[dict[str, Any]] = None,
          engine_root: Optional[Path] = None) -> None:
    """Every §4.4 fault, raised as `SoundError` naming the file and the key."""
    _keys(where, "", data, TOP_STORY if story else TOP_ENGINE)
    if data.get("version") != 1:
        raise _fault(where, "version", "must be 1")
    if not story:
        _keys(where, "limits", data.get("limits") or {}, LIMIT_KEYS)
    own = data.get("sounds") or {}
    _keys(where, "sounds", own, frozenset(own))
    for sid, row in own.items():
        _check_sound(where, str(sid), row, root, root if not story else engine_root)
    known = {**(engine_sounds or {}), **own}
    events = data.get("events") or {}
    if story:
        for name, row in events.items():
            if not NAME.match(str(name)) or str(name).startswith(ENGINE_FAMILIES):
                raise _fault(where, f"events.{name}", "must be a dotted id outside the engine's families")
            _keys(where, f"events.{name}", row, EVENT_KEYS)
    bind = data.get("bind") or {}
    allowed = set(ENGINE_EVENTS) | set(events)
    for event, value in bind.items():
        if event not in allowed:
            raise _fault(where, f"bind.{event}", "is neither an engine event nor declared in events:")
        _check_binding(where, f"bind.{event}", value, known)
    missing = (set(events) if story else set(ENGINE_EVENTS)) - set(bind)
    for event in sorted(missing):
        raise _fault(where, f"bind.{event}", "is declared and never bound")


def _check_binding(where: str, key: str, value: Any, known: dict[str, Any]) -> None:
    if value is None:
        return
    if isinstance(value, str):
        if value not in known:
            raise _fault(where, key, f"names no sound {value!r}")
        return
    row = _keys(where, key, value, frozenset({"default", "choices"}))
    choices = row.get("choices")
    if row.get("default") not in known or not isinstance(choices, list) or row["default"] not in choices:
        raise _fault(where, key, "needs a known default listed in its choices")
    category = known[row["default"]].get("category")
    for choice in choices:
        if choice not in known or known[choice].get("category") != category:
            raise _fault(where, f"{key}.choices", f"{choice!r} is unknown or of another category")


@lru_cache(maxsize=32)
def _load_file(path: str, mtime: float) -> dict[str, Any]:
    """One sounds.yaml, parsed; keyed on (path, mtime) so an edit is seen (spec §3, review M1)."""
    with open(path, encoding="utf-8") as handle:
        return yamlio.safe_load(handle) or {}


def _read(path: Path) -> dict[str, Any]:
    return _load_file(str(path), path.stat().st_mtime)


def engine_root() -> Path:
    return project_root() / str(get_config().get("sound.root") or "content/sounds")


def load_engine() -> dict[str, Any]:
    root = engine_root()
    data = _read(root / "sounds.yaml")
    check(data, where="content/sounds/sounds.yaml", root=root, story=False)
    return {"data": data, "root": root, "scope": ENGINE_SCOPE, "file": "content/sounds/sounds.yaml"}


def load_story(manifest: Any) -> Optional[dict[str, Any]]:
    """The story's `paths.sounds`, checked against the engine's set; None when it declares none."""
    rel = (manifest.paths or {}).get("sounds") if manifest is not None else None
    if not rel:
        return None
    root = manifest.resolve(rel)
    data = _read(root / "sounds.yaml")
    engine = load_engine()
    shown = f"{str(rel).rstrip('/')}/sounds.yaml"
    check(data, where=shown, root=root, story=True, engine_sounds=engine["data"]["sounds"], engine_root=engine["root"])
    return {"data": data, "root": root, "scope": manifest.slug, "file": shown}


def merge(engine: dict[str, Any], story: Optional[dict[str, Any]]) -> dict[str, Any]:
    """Engine sounds, then the story's by id; engine binds, then the story's (spec §4.3). Each row gains `scope`,
    `key` (the audition page's data key) and `overrides`."""
    out_sounds: dict[str, Any] = {}
    for src in (engine, story):
        if not src:
            continue
        for sid, row in (src["data"].get("sounds") or {}).items():
            out_sounds[sid] = {**row, "scope": src["scope"], "key": f"{src['file']} › sounds › {sid}",
                               "overrides": src is story and sid in (engine["data"].get("sounds") or {})}
    bind = {**(engine["data"].get("bind") or {}), **((story or {}).get("data", {}).get("bind") or {})}
    events = list(ENGINE_EVENTS) + [e for e in ((story or {}).get("data", {}).get("events") or {})]
    return {"limits": dict(engine["data"].get("limits") or {}), "events": events, "sounds": out_sounds, "bind": bind}


def merged(manifest: Any) -> dict[str, Any]:
    return merge(load_engine(), load_story(manifest))


def warm() -> None:
    """The WARMERS entry: the engine file and the active story's, parsed once at hosted start. `peek()` never
    activates a story (`None` loads the engine set alone), and nothing is swallowed: a broken sounds.yaml fails
    hosted start like any other content, as `caches.warm_all_caches` requires (pre-flight F16)."""
    from engine.games import registry

    merged(registry.peek())
```

```python
"""
Sound HTTP API (v0.24.0 spec §10): data and files only. The server never plays, mixes or synthesises.

    GET /api/sounds                 the running story's merged catalogue
    GET /api/sounds/catalog         the engine and every story, for the audition page
    GET /sound/<scope>/<path>       a file: scope `_engine` or a story slug declaring paths.sounds
"""

from __future__ import annotations

import logging
from typing import Any

from flask import Blueprint, jsonify

from engine.config import get_config

logger = logging.getLogger(__name__)
BLUEPRINT_NAME = "sounds"


def _hosted_slugs() -> list[str] | None:
    """`hosting.stories` when hosted, else None (local: every story). Read from config: local mode never imports
    engine.hosting."""
    if not get_config().get("hosting.enabled"):
        return None
    return [str(s) for s in (get_config().get("hosting.stories") or [])]


def _with_urls(catalogue: dict[str, Any]) -> dict[str, Any]:
    for row in catalogue["sounds"].values():
        if "file" in row:
            path = str(row["file"])
            scope, rel = ("_engine", path[len("engine:"):]) if path.startswith("engine:") else (row["scope"], path)
            row["url"] = f"/sound/{scope}/{rel}"
    return catalogue


def sounds_blueprint(name: str = BLUEPRINT_NAME) -> Blueprint:
    blueprint = Blueprint(name, __name__)

    @blueprint.get("/api/sounds")
    def api_sounds() -> Any:
        if not get_config().get("sound.enabled", True):
            return jsonify({"enabled": False})
        from engine.games import registry, sounds

        return jsonify({"enabled": True, **_with_urls(sounds.merged(registry.active()))})

    @blueprint.get("/api/sounds/catalog")
    def api_catalog() -> Any:
        from engine.games import registry, sounds

        allowed = _hosted_slugs()
        engine = sounds.merged(None)
        stories = []
        for slug, manifest in sorted(registry.discover().items()):
            if allowed is not None and slug not in allowed:
                continue
            story = sounds.load_story(manifest)
            merged = _with_urls(sounds.merge(sounds.load_engine(), story))
            stories.append({"slug": slug, "title": manifest.title, "declares": story is not None,
                            "events": merged["events"], "sounds": merged["sounds"], "bind": merged["bind"],
                            "overrides": sorted(k for k, v in merged["sounds"].items() if v.get("overrides"))})
        return jsonify({"engine": _with_urls(engine), "stories": stories})

    @blueprint.get("/sound/<scope>/<path:name>")
    def sound_file(scope: str, name: str) -> Any:
        from flask import send_file

        from engine.games import registry, sounds

        if scope == sounds.ENGINE_SCOPE:
            root = sounds.engine_root()
        else:
            allowed = _hosted_slugs()
            manifest = registry.get(scope)
            if manifest is None or not (manifest.paths or {}).get("sounds") or (allowed is not None and scope not in allowed):
                return jsonify({"error": "not found"}), 404
            root = manifest.resolve(manifest.paths["sounds"])
        if not name.endswith(".ogg") or not sounds.exists_exact(root, name):
            return jsonify({"error": "not found"}), 404       # also refuses any '..' part: it is in no listing
        response = send_file(root / name, mimetype="audio/ogg", conditional=True)
        response.headers["Cache-Control"] = f"private, max-age={int(get_config().get('sound.cache_seconds', 3600))}"
        return response

    return blueprint


__all__ = ["BLUEPRINT_NAME", "sounds_blueprint"]
```

```js
/** Synth sounds from data (v0.24.0 spec §4.2). Pure Web Audio; no state. */
const STEPS = { C: -9, D: -7, E: -5, F: -4, G: -2, A: 0, B: 2 };

export function noteHz(pitch) {
  if (typeof pitch === "number") return pitch;
  const m = /^([A-G])([#b]?)([0-8])$/.exec(String(pitch));
  if (!m) throw new Error(`not a note: ${pitch}`);
  const semis = STEPS[m[1]] + (m[2] === "#" ? 1 : m[2] === "b" ? -1 : 0) + (Number(m[3]) - 4) * 12;
  return 440 * Math.pow(2, semis / 12);
}

const layerMs = (l) => (l.start_ms || 0) + (l.attack_ms || 0) + (l.decay_ms || 0) + (l.hold_ms || 0) + (l.release_ms ?? 20);

export function durationMs(def) {
  let total = 0;
  if (def.layers) total = Math.max(...def.layers.map(layerMs));
  else if (def.sequence) total = Math.max(...def.sequence.notes.map(([at, , len]) => at + len + (def.sequence.voice.release_ms ?? 20)));
  const rep = def.repeat || { times: 1, gap_ms: 0 };
  return total * rep.times + (rep.gap_ms || 0) * (rep.times - 1);
}

let noise = null;
function noiseBuffer(ctx) {
  if (noise && noise.sampleRate === ctx.sampleRate) return noise;
  noise = ctx.createBuffer(1, ctx.sampleRate, ctx.sampleRate);
  const data = noise.getChannelData(0);
  for (let i = 0; i < data.length; i += 1) data[i] = Math.random() * 2 - 1;
  return noise;
}

function voice(ctx, layer, out, t0, freq, lengthMs, cents, sources) {
  const s = t0 + (layer.start_ms || 0) / 1000;
  const a = (layer.attack_ms || 0) / 1000;
  const d = (layer.decay_ms || 0) / 1000;
  const h = lengthMs != null ? Math.max(0, lengthMs / 1000 - a - d) : (layer.hold_ms || 0) / 1000;
  const r = (layer.release_ms ?? 20) / 1000;
  const peak = layer.gain ?? 1;
  const sus = (layer.sustain ?? 0) * peak;
  const env = ctx.createGain();
  env.gain.setValueAtTime(0, s);
  env.gain.linearRampToValueAtTime(peak, s + a);
  env.gain.linearRampToValueAtTime(sus, s + a + d);
  env.gain.setValueAtTime(sus, s + a + d + h);
  env.gain.linearRampToValueAtTime(0, s + a + d + h + r);
  let src;
  if (layer.wave === "noise") {
    src = ctx.createBufferSource();
    src.buffer = noiseBuffer(ctx);
  } else {
    src = ctx.createOscillator();
    src.type = layer.wave;
    src.frequency.setValueAtTime(freq, s);
    if (layer.to) src.frequency.exponentialRampToValueAtTime(layer.to, s + (layer.glide_ms || 0) / 1000);
    src.detune.setValueAtTime((layer.detune || 0) + cents, s);
  }
  let head = src;
  if (layer.filter) {
    const f = ctx.createBiquadFilter();
    f.type = layer.filter.type;
    f.frequency.setValueAtTime(layer.filter.freq, s);
    if (layer.filter.to) f.frequency.exponentialRampToValueAtTime(layer.filter.to, s + (layer.filter.glide_ms || 0) / 1000);
    if (layer.filter.q) f.Q.setValueAtTime(layer.filter.q, s);
    head.connect(f);
    head = f;
  }
  head.connect(env);
  if (layer.tremolo) {
    const lfo = ctx.createOscillator();
    const depth = ctx.createGain();
    lfo.frequency.setValueAtTime(layer.tremolo.rate_hz, s);
    depth.gain.setValueAtTime(layer.tremolo.depth * peak, s);
    lfo.connect(depth);
    depth.connect(env.gain);
    lfo.start(s);
    lfo.stop(s + a + d + h + r);
    sources.push(lfo);
  }
  env.connect(out);
  src.start(s);
  src.stop(s + a + d + h + r + 0.01);
  sources.push(src);
}

/** Schedule `def` on `ctx` into `out` at `when` (seconds). Returns the source nodes (the voice cap stops them). */
export function render(ctx, def, out, when) {
  const sources = [];
  const cents = def.jitter_cents ? (Math.random() * 2 - 1) * def.jitter_cents : 0;
  const rep = def.repeat || { times: 1, gap_ms: 0 };
  const once = durationMs({ ...def, repeat: undefined }) / 1000;
  for (let i = 0; i < rep.times; i += 1) {
    const t0 = when + i * (once + (rep.gap_ms || 0) / 1000);
    if (def.layers) for (const layer of def.layers) voice(ctx, layer, out, t0, layer.freq, null, cents, sources);
    else for (const [at, pitch, len] of def.sequence.notes) {
      voice(ctx, { ...def.sequence.voice, start_ms: at }, out, t0, noteHz(pitch), len, cents, sources);
    }
  }
  return sources;
}
```

```js
function unlock() {

}

function remember(k) {
  if (S.seen.has(k)) return;

  while (S.seenOrder.length > SEEN_MAX) S.seen.delete(S.seenOrder.shift());

function note(row) { if (S.log) { S.log.push(row); if (S.log.length > 200) S.log.shift(); } return row; }

export function resolve(event) {
  const cat = S.catalog;
  if (!cat || !cat.enabled) return { why: "unbound" };
  if (!cat.events.includes(event)) {
    if (S.strict) throw new Error(`no such sound event: ${event}`);
    return { why: "unbound" };
  }
  let id = cat.bind[event];
  if (id && typeof id === "object") id = (S.prefs?.soundChoices || {})[event] && id.choices.includes(S.prefs.soundChoices[event]) ? S.prefs.soundChoices[event] : id.default;
  return id && cat.sounds[id] ? { id, row: cat.sounds[id] } : { why: "unbound" };
}

export function play(event, { key, delayMs = 0 } = {}) {
  ensure();
  const base = { t: Date.now(), event, key };
  if (key != null && S.seen.has(String(key))) return note({ ...base, dropped: "seen" });
  const found = resolve(event);
  if (!found.id) return note({ ...base, dropped: found.why });
  if (key != null) remember(String(key));
  const { id, row } = found;
  const entry = { ...base, sound: id, category: row.category };
  if (!S.ctx) return note({ ...entry, dropped: "locked" });       // no gesture yet: dropped, never queued
  if (S.ctx.state !== "running") S.ctx.resume().catch(() => {});  // scheduled anyway; plays on resume (F33)
  const p = S.prefs || {};
  if (p.muted || (p.soundMaster ?? 0.8) === 0 || (p[PREF_OF[row.category]] ?? 1) === 0) return note({ ...entry, dropped: "muted" });
  if (p.quietInterface && !row.essential) return note({ ...entry, dropped: "quiet" });
  const gap = row.throttle_ms ?? S.catalog.limits.throttle_ms ?? 60;
  const now = performance.now();
  if (now - (S.last.get(id) ?? -Infinity) < gap) return note({ ...entry, dropped: "throttled" });
  S.last.set(id, now);
  S.plays = (S.plays || 0) + 1;
  const when = S.ctx.currentTime + delayMs / 1000;
  const out = S.ctx.createGain();
  out.gain.setValueAtTime(row.gain ?? 1, when);
  out.connect(S.buses[row.category]);
  const voice = { sources: [], entry: note({ ...entry }) };
  if (row.synth) voice.sources = render(S.ctx, row.synth, out, when);
  else playFile(row, out, when, voice);
  S.voices.push(voice);
  const cap = S.catalog.limits.voices ?? 8;
  while (S.voices.length > cap) {
    const old = S.voices.shift();
    for (const src of old.sources) { try { src.stop(); } catch { /* already stopped */ } }
    old.entry.stopped = true;
  }
  return voice.entry;
}

function playFile(row, out, when, voice) {
  const fallback = () => { voice.entry.fallback = true; voice.sources = render(S.ctx, row.fallback, out, when); };
  if (!S.oggOk || S.failed.has(row.url)) return fallback();
  const ready = S.buffers.get(row.url);
  if (ready && ready.duration !== undefined) {
    const src = S.ctx.createBufferSource();
    src.buffer = ready;
    src.playbackRate.setValueAtTime(row.rate ?? 1, when);
    src.connect(out);
    src.start(when, (row.start_ms || 0) / 1000);
    voice.sources = [src];
    return undefined;
  }
  fallback();                                            // the first play of a file is its fallback while it loads
  if (!ready) {
    const loading = fetch(row.url).then((r) => r.arrayBuffer()).then((b) => S.ctx.decodeAudioData(b))
      .then((buf) => S.buffers.set(row.url, buf))
      .catch((err) => { S.failed.add(row.url); S.buffers.delete(row.url); console.warn(`[sound] ${row.url} will play its fallback`, err); });
    S.buffers.set(row.url, loading);
  }
  return undefined;
}
```

```jsx
import { useEffect, useRef } from "react";

import { play } from "./engine.js";
import { turnSettled } from "./turns.js";

/** The narration <audio>'s volume: master x narration, 0 when muted (spec §7). */
export const narrationVolume = (p) => (p.muted ? 0 : (p.soundMaster ?? 0.8) * (p.volume ?? 0.8));

/**
 * turn.arrive or alert.error when a turn THIS PAGE sent ends (spec §6.3 rule 2; Plan decision 12): only with a
 * new turn payload since it went busy and the link live; a new run's settle is silent; a phone_up refusal is
 * silent. Runs every render, so its record is never stale.
 */
export function useTurnSounds({ busy, error, phoneUp, link, turns }) {
  const was = useRef({ busy, turnsAtBusy: turns });
  useEffect(() => {
    const prev = was.current;
    if (prev.busy && !busy) {
      const entry = turnSettled();
      if (entry && !entry.begin && link === "live") {
        if (error) {
          if (!phoneUp) play("alert.error");
        } else if (turns > prev.turnsAtBusy) {
          play("turn.arrive");
        }
      }
    }
    was.current = { busy, turnsAtBusy: busy && !prev.busy ? turns : prev.turnsAtBusy };
  });
}

/** link.lost / link.back, only after the link has once been live. */
export function useLinkSounds(link) {
  const state = useRef({ everLive: false, last: link });
  useEffect(() => {
    const s = state.current;
    if (s.everLive && s.last === "live" && link !== "live") play("link.lost");
    if (s.everLive && s.last !== "live" && link === "live") play("link.back");
    if (link === "live") s.everLive = true;
    s.last = link;
  }, [link]);
}
```

```python
from __future__ import annotations

import hashlib
from pathlib import Path

import yaml

from engine.games import registry, sounds

PACKS = {"Casino Audio", "RPG Audio", "Impact Sounds", "Sci-fi Sounds"}
ROW_KEYS = {"path", "sha256", "bytes", "author", "pack", "source_url", "archive", "archive_sha256", "member",
            "licence", "licence_file", "downloaded", "imported", "pack_version"}


def _roots() -> list[Path]:
    roots = [sounds.engine_root()]
    for manifest in registry.discover().values():
        if (manifest.paths or {}).get("sounds"):
            roots.append(manifest.resolve(manifest.paths["sounds"]))
    return roots


def test_every_file_has_one_row_and_every_row_a_file() -> None:
    for root in _roots():
        files = {p.relative_to(root).as_posix() for p in root.rglob("*.ogg")}
        prov = root / "PROVENANCE.yaml"
        rows = (yaml.safe_load(prov.read_text(encoding="utf-8")) or {}).get("files", []) if prov.is_file() else []
        paths = [r["path"] for r in rows]
        assert len(paths) == len(set(paths)), root
        assert set(paths) == files, (root, sorted(set(paths) ^ files))


def test_every_row_is_cc0_kenney_from_a_named_pack_and_matches_its_bytes() -> None:
    for root in _roots():

            assert row["author"] == "Kenney (www.kenney.nl)", row["path"]
```

```python
import struct
from pathlib import Path

PER_FILE = 48 * 1024


def _vorbis_header(data: bytes) -> tuple[int, int]:
    at = data.find(b"\x01vorbis")
    assert at >= 0, "no Vorbis identification header"
    channels = data[at + 11]
    (rate,) = struct.unpack("<I", data[at + 12: at + 16])
```

```python
"""
Import CC0 sound files from a downloaded pack (v0.24.0 spec §8.2).

    python -I scripts/import_sounds.py --archive <zip> --pack "RPG Audio" --page <asset page url>
        --member <path in zip> [--member ...] --licence-member License.txt --downloaded YYYY-MM-DD
        [--pack-version 1.0] --to <sounds dir>

Reads ONLY the named members (the archive is untrusted data: nothing else is extracted, nothing is run), copies
each byte-for-byte to <to>/files/kenney/<pack-slug>/<basename lower-cased>, copies the licence once to
<to>/LICENSES/kenney-<pack-slug>.txt (one per pack: each pack's own text), and appends one PROVENANCE.yaml row per file. Pure Python: Windows and Linux alike.
"""

from __future__ import annotations

import argparse
import datetime as dt
import hashlib
import re
import sys
import zipfile
from pathlib import Path, PurePosixPath

import yaml

AUTHOR = "Kenney (www.kenney.nl)"


def main(argv: list[str]) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--archive", required=True)
    ap.add_argument("--pack", required=True)
    ap.add_argument("--page", required=True)
    ap.add_argument("--member", action="append", required=True)
    ap.add_argument("--licence-member", required=True)
    ap.add_argument("--downloaded", required=True)
    ap.add_argument("--pack-version", default="")
    ap.add_argument("--to", required=True)
    args = ap.parse_args(argv)
    archive = Path(args.archive)
    to = Path(args.to)
    slug = re.sub(r"[^a-z0-9]+", "-", args.pack.lower()).strip("-")
    archive_sha = hashlib.sha256(archive.read_bytes()).hexdigest()
    prov_path = to / "PROVENANCE.yaml"
    prov = yaml.safe_load(prov_path.read_text(encoding="utf-8")) if prov_path.is_file() else None
    rows = (prov or {}).get("files", [])
    with zipfile.ZipFile(archive) as zf:
        licence = to / "LICENSES" / f"kenney-{slug}.txt"
        licence.parent.mkdir(parents=True, exist_ok=True)
        licence.write_bytes(zf.read(args.licence_member))
        for member in args.member:
            name = PurePosixPath(member).name
            if not name.lower().endswith(".ogg") or ".." in PurePosixPath(member).parts:
                raise SystemExit(f"refused member {member!r}: not a plain .ogg")
            data = zf.read(member)
            rel = f"files/kenney/{slug}/{name.lower()}"
            target = to / rel
            target.parent.mkdir(parents=True, exist_ok=True)
            target.write_bytes(data)
            row = {"path": rel, "sha256": hashlib.sha256(data).hexdigest(), "bytes": len(data), "author": AUTHOR,
                   "pack": args.pack, "source_url": args.page, "archive": archive.name, "archive_sha256": archive_sha,
                   "member": member, "licence": "CC0-1.0", "licence_file": f"LICENSES/kenney-{slug}.txt",
                   "downloaded": args.downloaded, "imported": dt.date.today().isoformat()}
            if args.pack_version:
                row["pack_version"] = args.pack_version
            rows = [r for r in rows if r["path"] != rel] + [row]
    header = "# Every shipped sound file (v0.24.0 spec §8.2). Written by scripts/import_sounds.py; do not hand-edit.\n"
    prov_path.write_text(header + yaml.safe_dump({"files": sorted(rows, key=lambda r: r["path"])}, sort_keys=False),
                         encoding="utf-8")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

```js
/**
 * READ RECEIPTS' sounds (v0.24.0 spec §9.7): one message, one sound; nothing for what an opening replays.
 * A message is keyed by its thread and time (Plan decision 1): the one key both carriers share.
 */
import { markSeen, playSound } from "@core/sound/index.js";

export const SOUND_EVENTS = Object.freeze([
  "phone.message_in", "phone.notify", "phone.buzz", "phone.ring", "phone.typing", "phone.send",
  "phone.unlock", "phone.lock", "phone.up", "phone.down", "phone.match", "phone.swipe", "scene.open",
]);
const RANK = ["phone.ring", "phone.buzz", "phone.message_in", "phone.notify"];
const DATING = new Set(["matchstick", "front_porch"]);              // phone/apps.js's dating apps (F14)

export const messageKey = (row) => `msg:${row.thread_id}@${row.last.at}`;
const matchKey = (row) => `match:${row.thread_id}`;
const sceneKey = (scene) => `scene:${scene.id}`;
const rows = (phone) => (phone && Array.isArray(phone.threads) ? phone.threads : []);
const fromThem = (row) => row.last && row.last.from !== "player" && !row.last.pending;

/** Every opening (a start, a resume, a rejoin): everything already on the phone is seen, and makes no sound. */
export function hydrate(phone) {
  const keys = [];
  for (const row of rows(phone)) {
    keys.push(matchKey(row));
    if (row.last) keys.push(messageKey(row));
  }
  if (phone && phone.scene && phone.scene.id) keys.push(sceneKey(phone.scene));
  markSeen(keys);
}

/** A row's newest message is fresh: from them, voiced, and new or newly voiced (pre-flight F2). */
function fresh(old, row) {
  if (!fromThem(row)) return false;
  return !old || !old.last || old.last.at !== row.last.at || Boolean(old.last.pending);
}

/** The sounds for what changed between two phone blocks. */
export function phoneSounds(prev, next, { openThread, up }) {
  const before = new Map(rows(prev).map((r) => [r.thread_id, r]));
  const found = [];
  for (const row of rows(next)) {
    const old = before.get(row.thread_id);
    if (!old && rows(prev).length && !row.last && DATING.has(row.app)) playSound("phone.match", { key: matchKey(row) });
    if (!fresh(old, row)) continue;
    const kind = row.last.kind;
    const event = kind === "voice" || kind === "video" ? "phone.ring"
      : !up ? "phone.buzz" : row.thread_id === openThread ? "phone.message_in" : "phone.notify";
    found.push({ event, key: messageKey(row) });
  }
  if (found.length) {
    found.sort((a, b) => RANK.indexOf(a.event) - RANK.indexOf(b.event));
    const [top, ...rest] = found;
    playSound(top.event, { key: top.key });
    markSeen(rest.map((f) => f.key));
  }
  const scene = next && next.scene;
  if (scene && scene.id) playSound("scene.open", { key: sceneKey(scene) });
}
```
