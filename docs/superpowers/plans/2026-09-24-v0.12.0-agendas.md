# v0.12.0 — Agendas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A generic, deterministic, authored system of NPC agendas — an owner, a goal, a story clock that measures it, moves the world makes on its own schedule, and reactions to what the player does — whose effects land through the same engine the player's actions use, whose moves the player learns about only when they could have, and whose hidden truths (the real Magpie) are chosen by the seed and masked until earned. Proven against HUE & CRY.

**Architecture:** `engine/world/agendas.py`, driven by `paths.agendas`. No model planning: every move is authored data evaluated by the engine. An agenda's progress IS a story clock (the existing `clocks.py` machinery; beats and `forces_scene` come free) advanced through the `value` effect. Moves and reactions run in an agendas pass inside `clock.advance_time`, walking whole in-game hour boundaries exactly as `law.propagate` does, on a new `AGENDA` stream, so a replayed seed with the same choices produces the same moves. There is no event bus: reactions are edge-triggered conditions (the shared condition grammar plus new Law/premise predicates), remembered in `GameState.agendas`. Moves leave traces the narrator sees only where and when the player could learn of them.

**Tech Stack:** Python 3.11, pytest, PyYAML.

**Spec:** `docs/superpowers/specs/2026-09-23-hue-and-cry-design.md` §5 (Agendas), with §6 (HUE & CRY: the seed picks the real Magpie from Wren, Silas and Imelda; Ardane's agenda does the doom clock's job; `spoilers.yaml` masks the name until earned). Read both and the cross-cutting rules before any task.

## Data contract (`paths.agendas` → one YAML file)

```yaml
roles:                         # seed-chosen hidden identities, derived (never stored)
  magpie:
    from: [npc_wren, npc_silas, npc_imelda]   # stable_rng(seed, "agenda:magpie").choice
    mask:                      # dynamic spoiler: the chosen NPC's display name is
      instead: "the Magpie"    # replaced by this text until `unmask_when` holds
      unmask_when: {flag: magpie_unmasked}

agendas:
  the_magpie:
    owner: {role: magpie}      # or an npc id
    goal: "steal every shining thing in Tallowmere"   # GM-facing only
    clock: magpie_spree        # a clock the story declares (state.yaml + paths.clocks)
    moves:
      - id: lift_a_shiny
        every_hours: 24        # cadence; first eligible at `start_hour` (default 0) after day 1 begins
        at_hours: [1, 2, 3]    # optional: only on these hours of the day
        when: {none: [{flag: magpie_caught}]}           # shared condition grammar
        select: {premise: {tier_min: 2, not_robbed: true, loot_tag: shiny}}
        effects:               # ordinary effects; {target} / {target_district} / {owner} substituted
          - {type: report, deed: burglary, guise: magpie, jurisdiction: "{target_jurisdiction}", precision: 0.6}
        advance: 1             # clock delta, applied through the `value` effect
        trace:                 # what it leaves behind
          text: "a black feather on the sill of {target_name}"
          where: target        # target | owner | <location id>
          public: false        # true: common talk — journaled unlocated at once
    reactions:
      - id: the_captain_hears
        on: {reported_to: {npc: npc_ardane, guise: magpie}}   # edge-triggered: fires when this becomes true
        once: true
        effects: []
        advance: 1

selectors:                     # (documentation of the grammar the loader accepts)
  premise: {district?, type?, tier_min?, tier_max?, not_robbed?, loot_tag?, owner?}
  fence:   {district?}                         # a vendor whose profile has `fence: true`
  witness: {knows: <guise>, jurisdiction?}     # an NPC holding a witness row for that guise
```

The loader validates: every `owner` is a scheduled NPC id or a declared role; every role's `from` are scheduled NPC ids; every `clock` is a clock the story declares (and is `visibility: hidden`); every `when`/`on`/`unmask_when` parses through the condition grammar (unknown predicate → load error naming the file); every selector key is known; effects are dicts with a `type`; every `trace.where` is `target`, `owner`, or a location id; cadence ≥ 1 hour. A story with agendas but no premises may not use the `premise` selector (load error), and one with no Law may not use `witness` or the Law predicates.

**Premise owners.** An anchor premise may declare `owner: <npc id>` (premises loader, optional, validated); a generated premise's owner is its first household member. `premises.owner(state, premise_id) -> str`.

## State shape (`GameState.agendas`, a dict; saved; default `{}`) — AS BUILT

```python
{"last_hour": 57,                         # absolute in-game hour the agendas pass last walked to
 "moves": {"the_magpie:lift_a_shiny": 49}, # per move: absolute hour it last fired
 "fired": ["the_magpie:the_captain_hears"],# once-reactions that have fired
 "truth": {"the_magpie:the_captain_hears": True},  # last evaluated truth, for edge triggers
 "hits": [{"agenda": "the_magpie", "premise": "prem_silk_row_2", "hour": 49}],  # premises an agenda robbed
 "trace_seq": 3,                           # counter `agenda_trace` allocates `t<n>` ids from
 "traces": [{"id": "t3", "agenda": "the_magpie", "text": "...", "where": "silk_row",
             "hour": 49, "public": False, "seen": False}]}
```

Matches the spec above with one addition: `trace_seq`, the saved counter
`agenda_trace` (`engine/game/effects.py`) increments to allocate each trace's
`t<n>` id, so ids stay stable and gapless across save/load rather than being
derived from `len(traces)` (which a future prune of shown traces would
collide on). Four effect kinds write this dict and nothing else does:
`agenda_mark` (`last_hour`/`moves`/`fired`/`truth`), `agenda_hit` (`hits`),
`agenda_trace` (`traces`, `trace_seq`), `agenda_trace_seen` (a trace's
`seen`).

### Task 2: moves on the clock

**Files:** `engine/world/agendas.py` (+`advance`, selectors), `engine/game/effects.py` (+`agenda_hit`, `agenda_trace`), `engine/game/rng.py` (+`AGENDA`), `engine/game/clock.py` (call `agendas.advance` after `jobs.tick`, guarded, in its own block), `engine/game/moved.py` (`"agenda"` kind). Test: `tests/test_agendas_moves.py`.

**Interfaces — Consumes:** Task 1's spec/roles/owner/`agenda_mark`. `premises.at/get`, `jobs.robbed`, `trade.vendors`, `law.jurisdiction_at`, `state.law["witnessed"]`, `law.same_person`, `quests.evaluate_condition`, `effects.apply_effects`, clock values via the `value` effect.
**Produces:** `agendas.advance(state, hours) -> list[dict]` (receipts, for tests and the harness); `agendas.select(state, selector) -> str | None`.

Rules:
- Walk each crossed whole-hour boundary from `last_hour` to now (cap 48 per call, as the Law does); for each boundary, in sorted agenda then move order: a move fires if its cadence has elapsed since it last fired (or it never has and `start_hour` has passed), `at_hours` (if given) contains the hour of day, `when` holds, and `select` returns a target. Firing applies `effects` (with `{target}`, `{target_name}`, `{target_district}`, `{target_jurisdiction}`, `{owner}` substituted in string values), advances the clock by `advance` through `value`, records `agenda_hit` when the target is a premise and the move's effects include a robbery marker (`robs: true` on the move — explicit, not inferred), writes the trace via `agenda_trace` (public → also `moved.note(kind="agenda")` unlocated at once), and stamps `moves` via `agenda_mark`. A move whose `select` finds nothing does not fire and does not stamp.
- Selectors: `premise` filters `premises.at`/all premises by district/type/tier/owner, `not_robbed` excludes both `jobs.robbed` and agenda `hits`, `loot_tag` requires a loot item carrying that tag; `fence` returns a fence vendor id (optionally in a district); `witness` returns an NPC holding a live witness row (not discharged/quashed) for a guise the watch links to `knows`. Candidates sorted; one `world_rng(state, AGENDA)` draw picks among them (zero draws when there is exactly one).
- `last_hour` starts at the hour the story begins (first `advance` call on a fresh state stamps it without firing anything for the past).
- Tests: a move fires on cadence and not before; `at_hours` honoured; `when` gates; a robbed premise (player or agenda) is never selected again when `not_robbed`; the Magpie-style `report` against `magpie` raises the linked `self` wanted band (proves moves reach the Law); traces recorded; public trace journaled; cut-invariance (12 × 1h == 1 × 12h, compare whole `state.agendas` and `state.law`); replay; background tick does not move agendas during a job; flagship + synthetic Law+jobs control unchanged.
