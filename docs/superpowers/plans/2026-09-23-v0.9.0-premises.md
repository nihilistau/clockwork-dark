# v0.9.0 — HUE & CRY skeleton + Premises Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a playable HUE & CRY skeleton (districts, cast, schedules, opening, one ending) and the generic Premises system (seeded houses/shops/palace wings inside districts, household routines, the `case` and `lift` verbs, stolen-goods provenance and fences), proven against that story.

**Architecture:** Premises are generated once at new game from the seed and live on `state.procgen.premises`; their households are procgen NPCs carrying routines, resolved by `npc_sim` exactly like scheduled NPCs, with "at home" resolving to an interior id `"{district}/{premise_id}"` that is not a travel-graph node. `case` and `lift` are ordinary intent verbs over registered `@skill`s. Every write goes through `effects.apply_effect` via three new effect kinds (`intel`, `provenance`, and `item` gaining `stolen_from`).

**Tech Stack:** Python 3.11, pytest, PyYAML; React 18 + vitest for the casing board.

**Spec:** `docs/superpowers/specs/2026-09-23-hue-and-cry-design.md` §3 (Premises), §6 (story). Read both before any task.

`types/<type>.yaml`:

```yaml
id: townhouse
label: townhouse
name_patterns: ["the {surname} townhouse", "Number {n}, {street}"]
tiers: {1: 5, 2: 3, 3: 1}              # wealth tier -> weight
household:                             # every member becomes a procgen NPC

    routine:                           # @home = this premise's interior; @work = one of work_at

  - role: cook
    routine: []                        # always at home
work_at: [wickmarket, chandlers_rise]  # candidate public places for @work
security:                              # drawn per tier: tier N draws N features
  - {id: good_lock, text: "a good lock on the street door", tier_min: 1}
  - {id: yard_dog,  text: "a dog in the yard after dark",    tier_min: 2}
loot:                                  # per tier, drawn rows = tier
  1: [{item_id: silver_spoons, weight: 3}]
  2: [{item_id: silver_spoons, weight: 2}, {item_id: pearl_brooch, weight: 1}]
  3: [{item_id: pearl_brooch, weight: 2}]
secrets:
  - {id: second_ledger, text: "a second set of books"}
```

`anchors/<anchor>.yaml`: same keys as a type, plus `district`, `name` (fixed), `tier` (fixed), and `security`/`loot`/`secrets` as FIXED lists (not pools).

### Task 4: `case` — watching a house

**Files:** `engine/world/premises.py` (+`intel_for`, `case`), `engine/game/effects.py` (+`intel` kind), `engine/game/state.py` (+`premise_intel: dict[str, list[str]]`), `engine/game/intents.py` (+`_case` builder, `SKILL_FOR_ACTION["case"] = "case_premise"`, `REFUSAL_KEY_FOR_ACTION["case"] = "ok"`, `to_tool_call` branch `{"premise_id": target}`), `engine/skills/builtin/thievery.py` (new, `@skill case_premise`), `engine/skills/builtin/__init__.py` (import it), `engine/agents/prompts.py` (+`district_block`, wired into `world_state_block` beside `_npcs_present_block`), `engine/agents/prompts.py::_SUMMARISERS` (+`case_premise`). Test: `tests/test_casing.py`.

**Behaviour:**
- `premises.intel_for(state, premise_id) -> list[dict]` — the premise's full intel list in a SEEDED order (derive a per-premise `stable_rng(state.rng_seed, PREMISES + ":" + premise_id)`), each `{"id", "text"}`:
  1. always first: occupancy — `"empty from 10:00 to 16:00"` computed from the household routines (the longest run of hours when no member resolves to the interior id; "never empty" if none).
  2. one entry per security feature (`text` from the spec).
  3. a loot hint — `"worth it: <item display name>"` for the most valuable loot item (`inventory.value_of`).
  4. if it has a secret: `"somebody here is hiding something"`.
- `premises.case(state, premise_id) -> dict`: refuses (`ok: False`, `message`) if the premise is not in the player's current district or everything is already known. Otherwise `advance_time(state, CASE_HOURS)` (`CASE_HOURS = 2`, a module constant), then `apply_effect(state, {"type": "intel", "premise": premise_id, "intel": next_id})`, and returns `{"ok": True, "premise": name, "learned": text, "known": n, "of": total, "hours": CASE_HOURS}`.
- `intel` effect kind: appends the id to `state.premise_intel[premise]` if absent; receipt text is the intel text.
- `_case(state)` offers every premise in `premises.at(state, state.location_id)` that has unknown intel, labelled `"watch <name>"`.
- `district_block(state) -> str`: `""` when undeclared or no premises here. Otherwise `"PREMISES HERE (what you know):"` then one line per premise: name, type label, and every KNOWN intel text; unknown ones are not mentioned at all. Never prints a premise id, a tier number, or loot the player has not learned.

### Task 5: `lift` and provenance

**Files:** `engine/world/thievery.py` (new), `engine/game/rng.py` (+`THIEVERY`), `engine/game/effects.py` (`item` kind: optional `stolen_from: {"whom": str, "where": str}` → also append to `state.provenance`; `provenance` kind for removal on sale), `engine/game/state.py` (+`provenance: dict[str, list[dict]]`), intents (`_lift`, `SKILL_FOR_ACTION["lift"] = "lift_purse"`, refusal key `ok`), `engine/skills/builtin/thievery.py` (+`@skill lift_purse`), summariser. Test: `tests/test_thievery.py`.

**Data contract** (`paths.thievery` → a YAML file):

```yaml
alertness: {default: standard, watch: hard, captain: severe, sergeant: hard, cook: easy}
purses:                                # by role; `default` required
  default: [{gold: [1, 4], weight: 4}, {item_id: brass_button, weight: 1}]
  steward: [{gold: [8, 20], weight: 3}, {item_id: signet_ring, weight: 1}]
hot_days: 7                            # goods stay hot this many days
```

**Behaviour:**
- `thievery.lift(state, npc_id)`: refuse unless the NPC is present at the player's (non-interior) location and awake. Roll `checks.resolve(state, "stealth", alertness[role] or default)`. Success/crit: draw one purse row on `world_rng(state, THIEVERY)`; gold via `apply_effect({"type": "gold", ...})`; an item via `apply_effect({"type": "item", "item_id": ..., "stolen_from": {"whom": npc_id, "where": location}})`. Partial: gold only, halved (min 1). Failure: nothing taken, and the result says the mark noticed (`"noticed": True`) — the Law release reads that; here it is only narrated. Never costs time beyond what `checks` does (a lift is a moment).
- `provenance` entries are `{"whom", "where", "day"}`; `thievery.heat(state, item_id) -> str` returns `"hot"` if any entry is younger than `hot_days`, or the item carries the tag `named` (inventory tags); `"cool"` if entries exist but all are older; `""` if never stolen.
- `_lift(state)` offers every present, awake NPC at a non-interior location, labelled `"lift <display name>'s purse"`; absent when `paths.thievery` is undeclared.
