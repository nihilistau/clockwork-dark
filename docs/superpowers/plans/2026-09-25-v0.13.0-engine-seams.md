# v0.13.0 — Engine seams for HUE & CRY's finish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the small engine seams that stand between the four shipped systems and a finished HUE & CRY: secret places that stay secret until found, a custody predicate and a jailbreak that can free you, world events that can force a scene, decks that can be dealt more than once, a terminal death that ends in an epilogue, a veiled "how clearly they know your face" word for the wanted poster, the job/death seam, and an art generator that works for any story.

No story content beyond the minimum fixtures; HUE & CRY content lands in the next stages.

**Tech Stack:** Python 3.11, pytest, PyYAML.

**Spec:** `docs/superpowers/specs/2026-09-23-hue-and-cry-design.md` §6 and Acceptance. v1.0.0 now ships as point releases (owner, 2026-09-25): v0.13.0 engine seams → living city → guild economy → Acts I–II → Act III + eight endings → simulate.py thief → UI plugin → art pack + live play, and v1.0.0 is tagged only at the end.

### Task 1: secret places stay secret until found

**Files:** `engine/game/intents.py` (`_travel`), `engine/game/effects.py` (a way to reveal: a `reveal_location {location}` effect that sets a durable known-location mark through state, or a documented flag convention `location_known:<id>` written by the existing `flag` kind — pick one, justify, document in AUTHORING), `engine/scenes/default_api.py` (the map payload must use the SAME predicate as `_travel`, so they can't drift — factor one `locations.is_known(state, loc_id)`), `engine/game/foraging.py` (a discovered hidden path counts as known). Test: `tests/test_secret_locations.py`.

- A `secret: true` location is offered by `_travel` only if the player has visited it, or it has been revealed, or it is the current location. The map payload uses the same function.
- `the-long-con` also declares secret locations: assert its new behaviour (a secret place is not offered until revealed) and confirm by reading its content that something reveals each one (a quest effect, a card, a path); if something that should reveal does not, record it and add the reveal in content only if trivial, else a CLAUDE.md deferred line.
- Tests: hue-and-cry turn one does not offer the Undercroft/Rooftop Road/Old Bell Tower; after the reveal it does; after visiting it stays; the map payload agrees with `_travel` in every case; the flagship's travel intent is byte-identical.
- [ ] Failing tests → implement → green → full suite → commit `wip T1: secret places stay secret`.
