# {{title}} — canon dictionary

The story bible, for humans and for prompts. Nothing in the engine reads this
file; everything that WRITES the story should. When a name, a spelling or a
fact is decided, it gets a line here — and when a prompt or a data file
disagrees with this file, this file wins and the other one is a bug.

Keep entries short. A dictionary you stop maintaining because it grew essays
is worse than none.
